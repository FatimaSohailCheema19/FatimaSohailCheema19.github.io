# Fatima Sohail — Portfolio

A responsive light-theme portfolio with data science, machine learning, research and web projects, plus a downloadable CV.

## Free hosting with GitHub Pages
1. Create a public repository named FatimaSohailCheema19.github.io on your GitHub account.
2. Extract this ZIP. Upload index.html, style.css, script.js, Fatima-Sohail-CV.pdf and .nojekyll to the repository root (not inside another folder).
3. Open Settings > Pages. Under Build and deployment, select Deploy from a branch.
4. Choose main and / (root), then Save.
5. GitHub will show the published URL after deployment finishes.

If that repository already exists, back up its contents before replacing files. A different public repository name can also be used for a project site.

## Updating the portfolio
- Edit project entries in script.js. Category keys: ml, data, apps.
- Edit your biography, education and section text in index.html.
- Replace Fatima-Sohail-CV.pdf with the latest CV using the same filename.
- Update colors and layout in style.css.
- Update the All work count in index.html when adding projects.

No build step or paid hosting is required. Google Fonts requires an internet connection; system fonts are used as fallback. The animated scatter graphic is illustrative, not project output. Project metrics come from the supplied CV and are experiment-specific.


## Vercel hosting
Upload the extracted website files to a GitHub repository, then import that repository into Vercel. Select Other as framework, leave Build Command empty and serve the repository root. No installation or build is required. The public production URL can be added to LinkedIn Contact info and Featured, and the GitHub profile Website field.

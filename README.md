## 📂 Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and portfolio content |
| `style.css` | Theme, layout, and responsive styling |
| `script.js` | Project cards, filters, and animation |
| `profile.jpeg` | Profile photograph |
| `Fatima-Sohail-CV.pdf` | Downloadable résumé |

## 🔄 Updating the Portfolio

- Update projects in `script.js`.
- Edit education, research, and other page content in `index.html`.
- Adjust the design in `style.css`.
- Replace `Fatima-Sohail-CV.pdf` to update the résumé.
- Commit changes to the publishing branch to trigger GitHub Pages deployment.

The animated scatter graphic is illustrative. Project descriptions and results refer to the individual academic projects and experiments.
